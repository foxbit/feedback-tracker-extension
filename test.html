Página de Teste da Extensão Feedback Tracker

Área de Teste 1

Esta é uma área que você pode selecionar para testar a captura de elementos.

Área de Teste 2

Outra área para testar a seleção de elementos diferentes.

Instruções:

  1. Abra a extensão clicando no ícone na barra de ferramentas
  2. Clique no botão "Selecionar Elemento"
  3. Selecione uma das áreas de teste acima
  4. Verifique se a captura funciona corretamente
