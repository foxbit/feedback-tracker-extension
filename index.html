🔒 Política de Privacidade

Feedback Tracker Extension

Última atualização: Dezembro 2024
Versão: 2.0

📋 Visão Geral

A extensão Feedback Tracker foi desenvolvida com foco na privacidade e transparência. Esta política explica quais dados coletamos, como os usamos e como protegemos sua privacidade.

Propósito único: Capturar elementos visuais de páginas web e criar automaticamente issues no Jira com screenshots para facilitar o processo de feedback e bug reporting.

📊 Coleta de Dados

✅ Dados que Coletamos

🔑 Informações de Autenticação
• Tokens de API do Jira fornecidos voluntariamente pelo usuário
• Armazenados localmente no navegador
• Nunca compartilhados com terceiros
🌐 Informações de Localização (URL)
• URL da página atual onde o feedback é capturado
• Título da página atual
• Usado exclusivamente para fornecer contexto ao issue no Jira
📸 Conteúdo Visual
• Screenshots apenas dos elementos específicos selecionados pelo usuário
• Capturados somente quando o usuário aciona a funcionalidade
• Anexados ao feedback no Jira
⚙️ Configurações
• Preferências do usuário (projeto Jira selecionado, servidor configurado)
• Armazenadas localmente para melhor experiência

❌ Dados que NÃO Coletamos

🚫 Informações Pessoais: Nome, endereço, e-mail, idade, números de identificação
🚫 Informações de Saúde: Dados médicos, histórico de saúde, sintomas
🚫 Informações Financeiras: Cartões de crédito, dados bancários, transações
🚫 Comunicações: E-mails, mensagens, conversas
🚫 Atividade Geral: Navegação, cliques, movimentos do mouse, teclas pressionadas

🎯 Uso dos Dados

Os dados coletados são usados exclusivamente para:

  • Autenticação: Conectar com sua instância do Jira
  • Contexto: Fornecer informações relevantes sobre a página onde o feedback foi capturado
  • Evidência Visual: Anexar screenshots dos elementos selecionados
  • Configuração: Manter suas preferências entre sessões

💾 Armazenamento e Compartilhamento

Armazenamento Local

Todos os dados são armazenados localmente no seu navegador usando a API de storage do Chrome. Nenhum dado é enviado para nossos servidores.

Compartilhamento Limitado

Os dados são compartilhados apenas com:

  • Seu servidor Jira: Para criar issues com o feedback
  • ImgBB: Para hospedagem temporária de screenshots (anexados ao Jira)

🔐 Segurança

  • Criptografia: Toda comunicação via HTTPS
  • Armazenamento Seguro: Tokens armazenados de forma segura no navegador
  • Acesso Limitado: Permissões mínimas necessárias
  • Sem Tracking: Não rastreamos atividade do usuário

👤 Seus Direitos

Você tem total controle sobre seus dados:

  • Acesso: Visualizar configurações na página de opções da extensão
  • Modificação: Alterar configurações a qualquer momento
  • Exclusão: Remover a extensão apaga todos os dados locais
  • Portabilidade: Exportar configurações se necessário

🔄 Atualizações da Política

Esta política pode ser atualizada ocasionalmente. Mudanças significativas serão comunicadas através de atualizações da extensão.
